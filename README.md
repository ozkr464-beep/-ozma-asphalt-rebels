## 🎮 Sobre el proyecto

OZMA: Asphalt Rebels es un videojuego web original ambientado en un universo de motociclismo urbano, con identidad visual Urban Predator.

El proyecto busca combinar motocicletas, personajes y escenarios originales con mecánicas de conducción, desafíos competitivos y sistemas de puntuación.

Su desarrollo será progresivo y estará vinculado a mi formación Full Stack Part Time en Soy Henry.

## 🎯 Objetivos

- Diseñar un universo visual y narrativo propio.
- Construir una experiencia web interactiva.
- Desarrollar controles y mecánicas de juego.
- Incorporar sistemas de puntuación.
- Implementar clasificaciones de jugadores.
- Aplicar conocimientos de frontend, backend y bases de datos.
- Publicar un prototipo jugable cuando esté técnicamente preparado.
